Draft a disciplinary warning letter — formal record of misconduct or rule violation.

# Required inputs
- Employee
- Specific incident(s) with dates
- Policy / rule violated
- Level of warning (verbal documented, written, final)
- Required corrective action
- Consequence of repetition

# Standard structure
1. Date + employee name + employer
2. Subject line: "Written Warning — [specific issue]"
3. Reference to incident: specific facts, dates, witnesses if applicable
4. Policy violated (cite specific clause or rule)
5. Previous discussions / verbal warnings (if any)
6. Required corrective action
7. Consequence of repetition (escalation to final warning, suspension, termination)
8. Acknowledgment line for employee
9. Signature + copy to HR file

# Progressive discipline ladder
1. Verbal documented coaching
2. Written warning
3. Final written warning
4. Suspension or termination

Most jurisdictions look favorably on documented progressive discipline before termination.

# Jurisdictional notes
- **LB Labor Code Art 75**: warning required before termination for certain types of misconduct
- **KSA Article 80**: termination requires documented warnings except for severe misconduct
- **UAE federal Decree-Law 33/2021**: progressive discipline expected but not strictly mandatory
- **DIFC**: ACAS-style principles; reasonable warning + improvement opportunity

# Drafting cautions
- **Stick to facts** — avoid characterization ("dishonest", "lazy") without evidence
- **Avoid protected categories** — issues must not correlate with protected characteristics
- **Equal treatment** — similar offenses get similar warnings across employees
- **Confidentiality** — the warning is in the employee's personnel file, not circulated
