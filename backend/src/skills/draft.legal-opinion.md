Draft a legal opinion — formal written analysis on a legal question, often relied upon for transactions.

# Required inputs
- Addressee (who's the opinion for?)
- Question(s) to be answered
- Facts (assumed or stated)
- Governing law
- Documents reviewed
- Purpose (transaction closing, advisory, regulatory filing)

# Standard structure
1. Header — "To: [client]; From: [firm/counsel]; Re: [matter]; Date:"
2. Background / facts (assumed)
3. Documents reviewed
4. Assumptions (e.g., authenticity of documents, capacity of signatories)
5. Qualifications (e.g., enforceability subject to bankruptcy, equitable principles, public policy)
6. Opinions (numbered) — each opinion = one clear conclusion
7. Reliance language (who may rely; for what purpose)
8. Limitations / disclaimers

# IRAC for each opinion paragraph
See [[output.IRAC-structure]]. Each opinion: state the question, recite the rule, apply to assumed facts, conclude.

# Transactional opinions (closing opinions)
Common in M&A / financing closings — opinion that (a) target is duly incorporated, (b) the document is enforceable, (c) execution is authorized, (d) no governmental approval required.

# Critical for malpractice
- State assumptions clearly — exclude what wasn't verified
- State qualifications clearly — what limits the opinion
- State reliance — only named parties; not for general circulation

See [[draft.memo-of-law]] for internal memos (less formal, broader scope).
