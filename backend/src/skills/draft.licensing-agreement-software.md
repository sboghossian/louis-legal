Software license agreement:
- Grant of license (scope, territory, term)
- License type (perpetual vs subscription vs term)
- User definition (concurrent users, named users, server license)
- Updates + maintenance
- Warranties (limited; typically 30 days)
- Liability cap
- IP indemnification
- Termination (for breach, insolvency)
- Open source disclosure
