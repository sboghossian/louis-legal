End-to-end brand protection program — register, monitor, enforce.

# Deliverables
1. **Trademark filings** — [[draft.trademark-application]] in each jurisdiction
2. **WIPO Madrid Protocol filing** — international coverage
3. **Domain name registrations** — defensive registrations
4. **Social media handles** — secure across platforms
5. **Brand book / use guidelines**
6. **Monitoring** — TM watch services, marketplace monitoring
7. **Enforcement playbook** — [[draft.cease-and-desist]], [[draft.takedown-DMCA]]

# Registration strategy
- File priority trademark applications in:
  - Home jurisdiction
  - All current operating markets
  - All near-term expansion markets
  - Strategic markets (anti-cybersquatting)
- File in relevant Nice Classes (typically 5-15 classes covering goods + services)
- Madrid Protocol designations for 10+ countries

# Monitoring
- **Trademark watch services** — alerts on similar new TM applications
- **Marketplace monitoring** — Amazon, Souq, Noon, local marketplaces
- **Domain monitoring** — typo-squatting + cybersquatting
- **Social media** — fake accounts, brand abuse
- **Counterfeit physical goods** — investigators in source markets

# Enforcement
1. **Cease & desist** — see [[draft.cease-and-desist]]
2. **Marketplace takedowns** — Amazon Brand Registry, IP infringement programs
3. **Domain UDRP / URS** — WIPO arbitration
4. **Customs recordation** — border seizure programs
5. **Civil litigation** — for serious / repeat infringers
6. **Criminal complaints** — for counterfeiting (KSA + UAE active)

# Brand-house structure
- IP holding company in tax-efficient jurisdiction
- Licensing back to operating entities
- Royalty payments per OECD transfer pricing rules
- Sharia compliance for ME holding companies

# Critical
- **Renewal calendaring** — TMs renew every 10 years; missed renewals lose protection
- **Use requirements** — non-use vulnerability after 3-5 years (jurisdiction-dependent)
- **Annual review** — portfolio audit, prune dormant marks, file new ones

Pair with [[draft.IP-assignment]] for ownership cleanup.
