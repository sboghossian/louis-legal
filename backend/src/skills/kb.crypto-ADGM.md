# ADGM Crypto Asset Framework — Quick Reference

## Overview
- **ADGM** — Abu Dhabi Global Market, established 2013
- **FSRA** — Financial Services Regulatory Authority (the regulator)
- Common-law jurisdiction with English-language legal framework
- First MENA jurisdiction to launch comprehensive crypto framework (2018)

## Regulated activities
Specified activities under FSRA include:
- **Operating a Multilateral Trading Facility (MTF)** — exchange
- **Custody of Accepted Virtual Assets**
- **Operating an Authorised Crypto Asset Service Provider** (ACASP)
- **Token issuance** (initial coin offerings + sustained issuances)
- **Investment Management** of crypto

## Accepted Crypto Assets list
- FSRA maintains an "Accepted Crypto Assets" list
- Must satisfy criteria: liquidity, security, transparency
- Current list includes Bitcoin, Ether, Solana, certain stablecoins
- Tokens not on list = not permitted for ADGM-licensed activities

## Licensing
- **ACASP** — Authorized Crypto Asset Service Provider license
- Combined with traditional FSRA categories where applicable
- Risk-based capital requirements
- Compliance + AML programs mandatory

## Token issuance regime
- **Token Sale Regulations** govern ICOs / IDOs / IEOs
- Disclosure document equivalent to prospectus
- Securities classification — if token = security, full securities regime applies
- Utility token + governance token specific guidance

## Custody requirements
- **Cold storage** preferences for client assets
- Segregation from proprietary holdings
- Insurance / surety obligations
- Specific cybersecurity standards

## DIFC vs ADGM crypto regime
- Both common-law; both robust
- ADGM has longer crypto track record
- DIFC's FSRA has its own framework
- Cross-licensing possible

## Recent developments
- **2024**: enhanced stablecoin regime
- **2025**: tokenized securities framework expanded
- Increasing alignment with EU MiCA + US SEC approaches

## Comparison to VARA (Dubai)
| | ADGM | VARA Dubai |
|---|---|---|
| Regulator | FSRA | VARA |
| Common-law | Yes | No (Dubai civil + emiri decrees) |
| Track record | 2018+ | 2022+ |
| Licensing types | ACASP + traditional | Tiered VA license |
| Best for | Institutional + complex products | Consumer + retail-facing |

## Practical
- Setup time: 6-9 months for full ACASP
- Capital: variable; minimum USD 1M+ typical
- Annual fees + audit costs significant
- Required local senior management
