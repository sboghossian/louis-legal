Draft an IP Licensing Agreement granting rights to use IP (patent / TM / copyright / trade secret / software).

# Required inputs
- Licensor + Licensee
- IP being licensed (precise description with registration numbers if any)
- Field of use (industry, application)
- Territory
- Exclusivity: exclusive / sole / non-exclusive
- Term
- Royalty structure (fixed / percentage / milestone-based / hybrid)
- Sublicense rights

# Structure
1. Definitions (Licensed IP, Territory, Field, Royalty, Net Sales, Sublicensee)
2. Grant of license (scope: make, use, sell, import, sublicense)
3. Reservations (Licensor retains all unlicensed rights)
4. Royalty + payment + reporting
5. Audit rights (typical: 2x/year, at Licensee's cost if material discrepancy >5%)
6. Maintenance + prosecution (who pays for patent maintenance fees, who controls prosecution)
7. Enforcement (right to sue infringers; cost + recovery allocation)
8. Reps & warranties (Licensor: ownership, no encumbrances, validity; Licensee: capacity)
9. Indemnification — see [[review.indemnification-balance]]
10. Improvements: assignment vs grant-back license
11. Term & termination (for cause; for breach; for non-payment; bankruptcy)
12. Post-termination: cessation of use, return/destruction, runoff inventory
13. Governing law

# Jurisdictional notes
- **DIFC/ADGM**: standard common-law IP licensing conventions
- **MENA-onshore**: ensure compliance with commercial agency laws (registered TM licenses may have agent-like consequences)
- **EU**: block exemption for tech transfer (Reg 316/2014); price-fixing restrictions on sublicensees

# Royalty pitfalls
- "Net Sales" definition — what's deducted? returns? taxes? rebates? — be precise
- Audit rights and currency conversion
- Stacking — multiple licensors can claim royalties on the same product
