MCP (Model Context Protocol) security:
- OAuth grants narrow + auditable
- Write actions default to 'requires approval'
- Per-tool capability scopes
- Audit logs for all MCP actions
- Rate-limit per tool
- Tenant isolation enforced at MCP layer
