Draft a Data Processing Agreement compliant with KSA Personal Data Protection Law (PDPL — Royal Decree M/19 2021, amended 2023).

# Required inputs
- Controller + Processor + roles
- Subject matter, purposes, categories of data subjects + data
- Sub-processors (with Controller approval mechanism)
- Cross-border transfer mechanism
- Retention periods

# PDPL key requirements (Art 27-32)
- Written contract required between controller and processor
- Processor must process only on documented instructions
- Confidentiality flow-down to personnel
- Appropriate technical + organizational measures
- Sub-processing requires controller consent
- Breach notification: 72 hours to SDAIA (Saudi Data & AI Authority); affected data subjects "without undue delay"
- Return/delete data at end of services

# Cross-border transfers
- Default: data localization preference
- Permitted transfers require: adequacy decision by SDAIA, appropriate safeguards (SCC-equivalent), or specific derogations
- Sensitive data transfers require additional safeguards

# Mandatory annexes
1. Subject matter + duration
2. Nature + purpose of processing
3. Categories of data subjects + personal data
4. Technical and organizational security measures (mapped to SDAIA Cybersecurity Controls)
5. Sub-processors with approval status
6. International transfer mechanism

# Bilingual
Arabic version required for SDAIA filings; English commonly used as parallel.

# Penalties
PDPL fines: up to SAR 5,000,000 + reputational + suspension orders. Surface this to user when negotiating caps.
