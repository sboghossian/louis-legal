End-to-end employee termination documentation pack.

# When to use
- Performance-based termination
- Position elimination / redundancy
- Mutual separation
- Termination for cause

# Pre-termination checklist
1. **Documentation review** — performance issues documented? (see [[draft.PIP-letter]], [[draft.warning-letter]])
2. **HR / legal review** — discrimination risks? protected category? recent complaints?
3. **Final pay calculation** — see [[tool.calculator-end-of-service-gratuity]]
4. **Replacement plan** — coverage of duties, knowledge transfer
5. **Property + access inventory** — laptop, badges, accounts, IP

# Deliverables
1. **Termination letter** — [[draft.termination-letter]]
2. **Severance agreement** (if applicable) — [[draft.severance-agreement]]
3. **Reference letter** — agreed terms (positive/neutral)
4. **Final settlement** — last salary + EOSG/EOSA + leave + ex gratia
5. **Visa cancellation** (for non-citizens in MENA) — coordinate timing
6. **MOHRE / Qiwa / NSSF deregistration**
7. **Confidentiality reminder** + return-of-property checklist
8. **Access revocation** — IT systems, building, accounts

# Day-of-termination
1. Schedule 1:1 meeting with manager + HR witness
2. Deliver termination letter
3. Discuss timeline + transitions
4. Provide severance agreement for review (typically 7-14 day consideration window)
5. Collect property + revoke access
6. Conduct exit interview (optional)

# Post-termination
- 7-14 day signed severance window
- Final payment processed
- Visa cancellation processed
- Employee handbook compliance — non-disparagement, return of property, IP confirmation
- Reference inquiries — limit to agreed terms

# Risk areas
- **Discrimination** — terminations correlated with protected status invite claims
- **Retaliation** — termination right after employee complaint
- **Mass redundancies** — additional consultation requirements
- **Recent equity grant** — vesting acceleration considerations

# Jurisdictional notes
- **UAE federal**: Decree-Law 33/2021 termination procedures; arbitrary dismissal compensation
- **KSA**: Article 80 for cause; Article 76 procedure
- **LB**: Labor Code Art 50 (without cause); Art 74 (cause)
- **DIFC**: DIFC Employment Law; statutory minimums
