Compare a legal issue across multiple jurisdictions.

# When to use
- User asks "how does X work in country A vs country B?"
- User is choosing a seat (where to incorporate / where to arbitrate)
- Cross-border deal — pick favorable governing law

# Output format
Table with one column per jurisdiction:

| Issue | LB | KSA | UAE federal | DIFC | UK | US-DE |
|-------|----|----|-------------|------|----|----|
| Statute | Civil Code | Royal Decree | Federal Decree-Law | DIFC Law | Common Law | Delaware GCL |
| Enforceability rule | … | … | … | … | … | … |
| Maximum duration | … | … | … | … | … | … |
| Bar | … | … | … | … | … | … |
| Risk | … | … | … | … | … | … |

# Categories to compare
Pick 5-8 relevant axes for the specific issue. Don't dump everything.

# Sources per cell
Cite per-cell — see [[output.inline-citations-with-pinpoints]].

# Conclusion
End with a 2-3 sentence summary: which jurisdiction is most/least favorable for the user's likely position and why.
