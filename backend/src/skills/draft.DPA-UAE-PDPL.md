Draft a Data Processing Agreement compliant with UAE Federal Decree-Law 45/2021 (Personal Data Protection Law).

# Required inputs
Same as GDPR DPA — see [[draft.DPA-GDPR]] — adapt clauses for UAE PDPL specifics below.

# UAE PDPL key requirements
- Written contract; processor follows controller's documented instructions only
- Security measures appropriate to risk (Article 20)
- Sub-processor requires prior written consent
- Breach notification: UAE Data Office "without undue delay" + affected individuals if high risk
- Return/destroy data at end of services
- Data subject rights: access, rectification, erasure, restriction, portability, objection

# Cross-border transfers (Article 22-23)
- Permitted to "adequate" jurisdictions (list pending; EU/UK/CH expected)
- Otherwise: SCC-equivalent contractual safeguards, BCRs, or specific derogations (consent, contractual necessity)
- Free zones (DIFC, ADGM) have their own separate data protection regimes (DIFC Law 5/2020, ADGM Data Protection Regulations 2021) — DPA may need to be tailored to which entity operates where

# DIFC and ADGM
- DIFC: DIFC Law 5/2020 (closely modeled on GDPR; ICO-equivalent oversight)
- ADGM: ADGM Data Protection Regulations 2021 (also GDPR-flavored)
- If your processor is DIFC/ADGM-incorporated, use the respective regime's standard contractual clauses

# Bilingual
Arabic mandatory for onshore federal filings; English commonly the working language.

# Penalties
UAE PDPL: fines + reputational + administrative orders. Specific penalty tables pending in implementing regulations.
