Draft Terms of Service / Terms of Use for a website, app, or platform.

# Required inputs
- Service description (what is it?)
- Operator entity + jurisdiction
- User base: B2C, B2B, both
- Payment-handling (free / paid / freemium)
- User-generated content (yes/no)
- Data processing (link to Privacy Policy)
- Age requirement
- Disputes mechanism

# Standard sections
1. **Acceptance** — user agrees to ToS by using the service
2. **Eligibility** — age, jurisdiction, capacity
3. **Account creation** — username/password obligations, suspension rights
4. **Acceptable use** — prohibitions (illegal, harmful, IP-infringing, spam)
5. **User content** — license to operator (worldwide, royalty-free, sub-licensable, perpetual or term-limited)
6. **IP** — Operator's IP retained; user content remains user's (subject to license)
7. **Payment** (if applicable) — pricing, refunds, taxes, auto-renewal disclosures
8. **Disclaimers** — "AS IS"; merchantability + fitness disclaimed where permitted
9. **Limitation of liability** — capped at fees paid in 12 months (or USD/EUR amount if free)
10. **Indemnification** — user indemnifies operator for user's content / use violations
11. **Termination** — by either side; consequence on user data
12. **Modification** — operator may modify with notice; continued use = acceptance
13. **Governing law + forum** — choose carefully; consumer-protection laws override forum-selection in many jurisdictions
14. **Contact**

# Jurisdiction-specific
- **EU** consumer rights (Directive 2011/83/EU + national implementations): 14-day withdrawal for distance contracts, no class-action waivers vs consumers, mandatory languages
- **CCPA / state US**: arbitration with class-action waivers permissible if carefully drafted; AAA / JAMS rules common
- **MENA**: less codified consumer-law overlay, but UAE Federal Law 4/2022 on consumer protection now significant; KSA Consumer Protection Law
