Implement GDPR (or PDPL) compliance for an organization.

# Phases
1. **Data mapping** — what's collected, from whom, for what, where stored
2. **Lawful basis assignment** — per processing activity
3. **Privacy notice rewrite** — [[draft.privacy-policy]]
4. **Consent mechanism** — granular UI for cookies, marketing, optional features
5. **DSR process** — handling access/rectification/erasure requests within timeline
6. **Breach response** — playbook + 72-hour notification process
7. **Vendor DPAs** — [[draft.DPA-GDPR]] with every processor
8. **International transfers** — SCCs or equivalent for non-adequate jurisdictions
9. **Records of processing** (Art 30) — maintained
10. **DPIA template** — for high-risk processing
11. **Training** — staff awareness program
12. **Governance** — DPO appointment if needed; privacy committee

# Deliverables
- Data inventory
- Updated privacy notice
- Cookie banner + preference center
- Internal SOPs (DSR, breach, DPIA)
- Vendor DPAs signed
- SCC / IDTA for international transfers
- Training records
- Compliance dashboard

# Timeline
Typical 90-180 days for medium-size org; longer for complex.

See [[review.GDPR-readiness]] for the audit input.
