Detect when user is asking about specific Louis features.

# Patterns
- "Does Louis support [X]?"
- "Can I do [X] with Louis?"
- "How do I [X]?"
- Specific product / feature names

# Response actions
- Direct answer with feature description
- Deep-link to `/features/:slug` if a canonical page exists
- Deep-link to `/use-cases/:slug` for use-case framing
- Deep-link to `/ai-features/:slug` for AI-specific features
- Offer live demo if user shows buying intent

# Feature catalog (representative)
- Doc workspace
- Drafting board
- Skills router
- Multi-jurisdictional support
- Bilingual drafting
- Customize
- Routines
- e-Firm features (matter, billing, team)
- Word plugin
- Mobile app
- API access (enterprise)

# Critical
- **Don't oversell** — describe what works today, flag what's roadmap
- **Surface real demo** when possible (not just words)
- **Offer escalation** for complex enterprise questions

See [[justice.intent.competitor-comparison]] for "how does this compare to X" questions.
