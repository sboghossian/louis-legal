Draft a Performance Improvement Plan (PIP) — formal documentation of performance issues with improvement objectives.

# Required inputs
- Employee + Manager / HR contact
- Specific performance issues (with examples)
- Improvement objectives (SMART: Specific, Measurable, Achievable, Relevant, Time-bound)
- Review timeline + checkpoint dates
- Consequences of non-improvement

# Standard structure
1. Header — date, employee name, role
2. **Specific issues identified** — with examples and dates
3. **Objectives** — what must improve (3-5 typical)
4. **Success metrics** — how performance is measured
5. **Timeline** — typically 30/60/90-day plan with checkpoints
6. **Support provided** — training, mentoring, resources
7. **Consequences if not improved** — termination, role change
8. Acknowledgment / signature block

# Best practices
- **Avoid pretextual PIPs** — if termination is decided, PIP is risky pretext for wrongful dismissal claim
- **Specificity over generality** — "improve communication" is bad; "respond to client emails within 24h" is good
- **Reasonable objectives** — courts review whether goals were achievable
- **Documented support** — manager actually provided coaching
- **Consistent treatment** — similar PIPs for similar issues across employees
- **HR review** — never a manager-alone document

# Jurisdictional considerations
- **UAE federal**: PIP common practice but not statutorily required; termination for cause must be procedurally clean
- **KSA**: Article 80 termination requires documented grounds + Qiwa registration
- **LB**: Labor Code Art 74 requires specific grounds; PIP supports the documentation chain
- **DIFC**: standard common-law principles; PIP useful for fair-process defense

# Anti-pattern
- PIP issued during/right after employee complaint or whistleblowing → retaliation claim risk
- Generic templates without specifics → reduces evidentiary value
- "Improve attitude" — non-actionable; describes specific behaviors instead
