Generate "WHEREAS" recital clauses that frame the deal.

# Pattern
- 3-7 recitals, each one sentence
- Establish: parties' identity → purpose / occasion → mutual interest → desire to formalize
- End with: "NOW, THEREFORE, in consideration of the mutual covenants…"

# Example structure
1. WHEREAS [Party A] is a [description and business];
2. WHEREAS [Party B] is a [description];
3. WHEREAS the Parties wish to [purpose];
4. WHEREAS the Parties have agreed on the terms set forth herein;
5. NOW, THEREFORE, in consideration of the mutual promises…

# Civil-law adaptation
French / Lebanese / Arabic civil-law contracts often use "Préambule" or "تمهيد" with a few paragraphs of context rather than enumerated WHEREAS clauses. Match the tradition of the jurisdiction.
