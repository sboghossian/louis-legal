Pre-litigation documentation pack — before filing court / arbitration.

# Steps + deliverables

## Step 1: Assess
- Document the dispute facts (chronological narrative)
- Identify legal claims (cause of action, governing law)
- Calculate damages
- Assess statute of limitations
- Run conflict check ([[efirm.conflict-check]])

## Step 2: Send pre-action correspondence
1. **Demand letter** ([[draft.demand-letter]]) — clear demand + deadline + consequence
2. If applicable: **Cease and Desist letter** ([[draft.cease-and-desist]])
3. Document all communications + responses

## Step 3: Negotiate / mediate (if appropriate)
- Mediation often required by court rules or contract clause
- Settlement offer with reservation of rights
- Without-prejudice communications
- Mediation agreement (if formal)

## Step 4: Statute / deadline review
- Limitation periods: typical ranges
  - Contract: 6-15 years jurisdiction-dependent
  - Tort: 3-6 years
  - Specific statutes: shorter (1-3 years for some employment)
- File before expiry; suspend negotiations if approaching

## Step 5: Pre-filing
- **Arbitration clause check** — go to arbitration instead of court?
- **Forum + jurisdiction analysis** — where to file
- **Counsel engagement** ([[draft.engagement-letter]])
- **Funder discussion** — third-party litigation funding for large cases
- **Insurance notification** — D&O, E&O policies may require timely notice

## Step 6: Filing decision
- File complaint ([[draft.litigation-complaint]]) OR arbitration request ([[draft.arbitration-request]])
- Court / tribunal fee
- Service on respondent
- Interim relief application if urgent

# Critical
- **Statute clock** is paramount — track + file before deadline
- **Document everything** — pre-litigation conduct becomes evidence
- **Engagement letter** before substantive work
- **Settlement offers** — without-prejudice marking for negotiation protection
