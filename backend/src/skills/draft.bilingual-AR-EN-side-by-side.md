Draft bilingual Arabic-English documents with mirror clauses.

# Layout
- Two-column table OR sequential clause-by-clause with Arabic first then English (LB convention) or English first then Arabic (DIFC/ADGM convention)
- Every clause number matches across languages
- Schedule items match across languages

# Controlling language
- LB onshore: Arabic is usually the legally controlling version
- UAE federal: Arabic controls in onshore courts; English controls in DIFC/ADGM if so stated
- KSA: Arabic controls
- Always state controlling language explicitly: *"In the event of conflict, the [Arabic/English] version shall prevail."*

# Translation quality
- Use legal-register Arabic, not colloquial
- Match defined terms exactly (define once in each language, reference consistently)
- Numerals: Western Arabic numerals (1,2,3) work in both versions
- Currency: write the code (LBP, AED, SAR, USD) — not the symbol — to avoid RTL/LTR rendering issues
