A 20-minute workflow for redlining a contract — produces a deliverable redline + memo.

# Steps (target 20 min total)

**Minutes 0-2: Setup**
- Identify contract type (NDA / MSA / lease / employment / SPA)
- Identify user's side (buyer/seller, employer/employee, etc.)
- Identify jurisdiction + matter priorities
- Load the relevant skills: e.g., [[review.MSA-deep-review]] + [[review.indemnification-balance]] + [[review.liability-cap-reasonableness]]

**Minutes 2-7: Triage**
- Run [[review.missing-clauses]] — what's absent?
- Run [[review.risk-flagging]] — what's atypical?
- Scan top 5 value clauses (liability, indemnity, IP, termination, dispute resolution)

**Minutes 7-17: Redline**
- Per clause: current text → proposed text → 1-sentence rationale → severity
- Build the memo in parallel (top-10 list)

**Minutes 17-19: Polish**
- Reorder by severity for the executive summary
- Add fallback positions for ambiguous calls
- Add open questions / requests for further input

**Minutes 19-20: Output**
- Memo (BLUF + redlines + open issues)
- Track-change-style document if requested
