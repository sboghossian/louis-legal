Draft a trademark application or specification.

# Required inputs
- Applicant (legal name + entity type + address)
- Mark (word / device / combined / sound / 3D)
- Class(es) under Nice Classification (Classes 1-45)
- Goods / services specification per class
- Priority claim (if earlier filing in another jurisdiction within 6 months)

# Nice Classification basics
- Classes 1-34: goods
- Classes 35-45: services
- Each class is a separate filing fee
- Specifications must be precise — too vague rejected; too broad may be limited by examiner

# Specification drafting
- **Precise**: "computer software for legal document analysis and contract review" — good
- **Too vague**: "computer software" — examiner may require specification
- **Too broad**: "all goods and services" — non-allowed under most regimes
- Use Nice Classification's pre-approved terms where possible (faster examination)

# Per-jurisdiction
- **WIPO Madrid System** — one filing covers up to 100+ jurisdictions; basic mark + designations
- **GCC TM Office (KSA, UAE, BH, OM, KW, QA)** — unified gulf application possible
- **UAE federal** — UAE MOEC TM registry
- **KSA** — Saudi Authority for Intellectual Property (SAIP)
- **LB** — Ministry of Economy & Trade IP office
- **EUIPO** — EU-wide trademark (one filing, all 27 member states)

# Standard sections
1. Applicant details (legal name + address)
2. Representative (if any)
3. Mark representation (image / wording / type)
4. Classes + specification
5. Priority claim with earlier filing details
6. Use claims (intent-to-use vs use-in-commerce; differs by jurisdiction)
7. Power of Attorney (for foreign applicants)
8. Apostille / legalization of POA (in many MENA jurisdictions)

# Anti-pattern
Don't file with a vague mark image or with overly broad specifications — saves filing fees short-term but causes examination delays and weakens enforceability.
