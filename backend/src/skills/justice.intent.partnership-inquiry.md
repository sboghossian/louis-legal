Detect when user is exploring strategic partnerships with HAQQ.

# Patterns
- "partnership"
- "collaboration"
- "integration"
- "reseller"
- "white label"
- "API partner"
- "channel partner"

# Response actions
- Route to `/partnership` (partner program page)
- Identify partnership type
- Capture lead details for partnerships team

# Partnership types
1. **Bar association partnerships** — CLE + member benefits
2. **Law firm partnerships** — preferred-vendor agreements
3. **Tech integrations** — Tawqi3i, Microsoft Word, Slack, etc.
4. **Marketplace partnerships** — Salesforce AppExchange-style listings
5. **Education partnerships** — law school programs
6. **Press / media partnerships** — content co-creation

2. Capture lead details (name, org, role, partnership idea)
