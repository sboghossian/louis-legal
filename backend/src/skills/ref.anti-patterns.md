Common anti-patterns in legal-AI use:
- Over-trusting AI outputs without verification
- Sending privileged content without redaction
- Using AI as the lawyer (UPL risk)
- Skipping jurisdiction verification
- Pasting case citations without checking they exist
- Treating AI as substitute for client conversation
- Long unstructured prompts (worse output)
- Repeated same prompt expecting different results
