End-to-end employee hiring document pack.

# Deliverables
1. **Offer letter** — [[draft.offer-letter]]
2. **Employment contract** (jurisdiction-specific): [[draft.employment-contract-LB]] / [[draft.employment-contract-KSA]] / [[draft.employment-contract-UAE]]
3. **Confidentiality + IP assignment** — [[draft.IP-assignment]] (often integrated into contract)
4. **Restrictive covenants** (if any) — [[draft.non-compete]] / [[draft.non-solicit]]
5. **Equity grant letter** (if applicable) — separate doc; vesting schedule attached
6. **Employee handbook** — firm-wide policies + sector-specific (often pre-existing)
7. **Background check + reference release** — separate consent forms
8. **Visa + work permit sponsorship** (for non-citizens in MENA)
9. **MOHRE / Qiwa / NSSF registration** — government filings
10. **Equipment + access provisioning** — IT setup, system access, building access

# Workflow steps
1. Job offer accepted
2. Background check + reference verification
3. Contract drafting (auto-populated from offer)
4. Visa/permit application (parallel for non-citizens)
5. Government registrations
6. Equipment provisioning
7. Day 1: orientation + handbook acknowledgment + IT setup
8. Probation review at 90 days
