Cross-border document use frequently requires authentication chains. Surface these requirements proactively.

# Authentication chain (Hague Apostille)
1. Notary Public — certifies signature
2. Apostille — issued by designated authority (state department / ministry of foreign affairs)
3. Document recognized in all Apostille-signatory countries

## Apostille signatories
~120 countries including UK, EU, US, UAE, India, Japan, Australia, etc.

## Non-signatories (consular legalization required)
- KSA, Egypt, UAE-onshore for some doc types, Iran, others
- Chain: Notary → MFA (origin) → consulate (destination)

# When notarization is needed
- Power of Attorney for use abroad
- Real estate transfers
- Marriage / divorce / personal status documents
- Court filings using foreign-issued documents
- Corporate documents (board resolutions, certificates of incumbency)

# Jurisdictional notarization specifics
- **LB**: Notaire Public; chain via MFA + destination consulate
- **KSA**: Notary Public; sometimes via Saudi embassy for foreign docs
- **UAE**: Notary Public (federal or emirate); MOFA attestation; legalization
- **DIFC / ADGM**: own notarial regimes; recognize incoming notarial chains
- **Tawqi3i**: Lebanese e-notarization; cross-border recognition still developing

# Apostille shortcut
If both jurisdictions are Apostille signatories: notary → apostille → done.
If not: full consular chain.

# Critical
- **Verify the chain** before client commits — incorrect authentication delays transactions weeks
- **Sworn translation** often required alongside notarized original
- **Validity period** — some apostilles + legalizations have expiry dates
